# D7 盲化协议

## 为什么不再用「打分」

单人、单轮、知道每份产物出处的判断，只能当印象。**分差与置信区间需要独立评审者**，本协议不产出这两样，
只产出「哪些判定稳定、哪些判定会翻」。

## 五条判据（评分前写定，此后不许改）

对每个（问题，臂）组合，只判这 5 条是与否，不判好坏程度：

| 代号 | 判据 | 通过条件 |
|---|---|---|
| C1 | 给立场 | 明确回答「先做什么」，不是罗列可能性 |
| C2 | 给做法 | 给出可执行动作（改哪一处 / 补哪一节 / 跑哪条检查） |
| C3 | 给依据 | 说明为什么，且依据来自对象本身（可指回原文/机制） |
| C4 | 给边界 | 指出该方法在什么条件下不成立或会失效 |
| C5 | 不失真 | 没有为了显得全面而把没有证据的事说成结论 |

命中数 = 5 条中通过条数（0–5）。

## 遮蔽规则

1. 臂标签随机化为 `P1…Pn`（含空臂，空臂就是「不给产物，只凭通用知识答」）。
2. 每轮的臂顺序重新打乱，用 `--seed` 固定，保证可复现。
3. 评完当轮全部组合后，才允许 `--reveal` 看映射。
4. 同一问题、同一臂，三轮独立评分，中间不回顾上一轮结果。

## 结论口径

- 每臂三轮取多数（3 轮里 ≥2 轮同值才算稳定）。
- 两臂命中数差 ≤1 → **不可区分**，禁止写「略好」。
- 差 ≥2 且三轮一致 → 才允许写「A 在该问题上更可用」。
- 空臂赢了的条目要单列：说明产物在该问题上**不如没有**。

## 污染声明（必须随结果一起发表）

评审者与产物生成者是同一模型、同一会话。遮蔽只能压住「知道出处」这一层污染，
压不住「记得自己写过什么」。因此本协议的结果只作**弱证据**，不进 SKILL 纪律，只进观察期台账。
